# E-Commerce Automation Project

## Description
This project automates key e-commerce functionalities using Selenium WebDriver and Java.

## Features
- Login functionality
- Product search
- Add to Cart functionality
- Web element identification using XPath

## Technologies Used
- Java
- Selenium WebDriver
- Eclipse IDE
- ChromeDriver

## Project Structure
- src/
- Login Test
- Search Product Test
- Add to Cart Test

## How to Run
1. Open the project in Eclipse.
2. Add Selenium JAR files to the project build path.
3. Ensure ChromeDriver is configured.
4. Run the Java test class.
